# Mick-G

Static PWA for GitHub Pages: **MICK G — The Ballincollig Files**.

## Launch

The site is deployed automatically by the `Deploy static site to GitHub Pages` workflow on every push to `main`.

Once GitHub Pages is enabled with **Settings → Pages → Build and deployment → Source: GitHub Actions**, open:

**https://jackmulcair-hue.github.io/Mick-G/**

The workflow can also be started manually from the **Actions** tab with **Run workflow**.

## What’s included

- Responsive, mobile-first noir interface
- Home, range, ledger, stash, and status screens
- Fictional target practice mini-game with score and streak tracking
- Local audio upload and playlist controls
- Installable PWA manifest with relative Pages-safe scope and start URL
- No bundled copyrighted music

## Development

This is a dependency-free static site. Open `index.html` locally for a quick preview, or serve the repository directory with any static HTTP server to test PWA behavior.
