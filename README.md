# Mick-G

Mick G is a dependency-free fictional noir strategy game/PWA for GitHub Pages.

## v2 gameplay upgrade

The app now uses a persistent career loop rather than a repeatable stash button:

- Timed operations with different windows, crew requirements, rewards and heat consequences
- Cash, notoriety, crew availability, time-of-night and rank progression
- Fictional non-graphic strategy missions where the player assigns crew and manages consequences
- A precision range with ammo, misses, streaks, accuracy, score and equipment upgrades
- Achievement tracking, tutorials, career history and local save persistence
- Responsive visual refresh with a live city mood, resource dashboard and operation board

All characters and activities are fictional. The game does not provide real-world targets or instructions.

## Deploy

GitHub Pages uses the `Deploy static site to GitHub Pages` workflow on pushes to `main`.

Set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**, then visit:

**https://jackmulcair-hue.github.io/Mick-G/**
